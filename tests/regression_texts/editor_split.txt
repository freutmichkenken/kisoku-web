# 手順: この文章を docx にして読み込む → 第１条を開く → 第３項の「…」→「ここから新しい条にする」
#       → 「前の条にまとめる」→ 取消 →「元に戻す」
# 期待: 分割後、新しい第２条のタイトルが「本採用拒否」、本文が「次の各号に…」で、号と次の項も移る。
#       元の第２条（労働条件）は第３条になる。まとめると第１条の項が４つに戻り、
#       「元に戻す」1回で分割した状態に戻る
